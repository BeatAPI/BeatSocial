# 竞对刷新（每周一次，给 Grok bot 抓取 + Claude 拆解）

## A. 抓取和筛选（Grok bot，用便宜模型或脚本）

```text
你负责刷新 BeatSocial 对标库。
1. beatsocial competitor list 和 beatsocial account list，按账号的平台和市场确定要看的竞对账号。
2. 用 Social Data API（或平台公开数据）抓每个竞对账号最近 7 天的帖子和公开指标。
3. 只保留互动明显高于该账号平时水平的帖子（例如曝光或点赞排前 20%），每个账号最多 5 条。
4. 每条写入：
   beatsocial sample add --url <原帖链接> competitor=<竞对ID> platform=x country=GLOBAL type=<对应我们的内容类型> \
     for_account=<我们的哪个账号参考> hook="<原文开头一句>" impressions=<数> likes=<数> replies=<数> \
     posted_at=<日期> observed_at=<今天> evidence_note="<数据来源和边界>" --by <bot名>
   拿不到的指标不写，不要填 0。
5. 新竞对先建：beatsocial competitor add <id> --name "<名字>" --why "<为什么对标>"
```

## B. 拆解（Claude 写稿前，或每周一次）

```text
beatsocial sample list --limit 30，找出还没有 structure 或 how_to_adapt 的新样本。
每条打开原帖，补两项（用 sample add 同一个 url 更新）：
- structure：开头 → 痛点 → 解法 → 数字 → CTA 这样的结构链
- how_to_adapt：换成 BeatAPI 自己的事实时怎么写，哪些不能照搬（对方的客户、价格、基础设施）
拆解长文可以另存 memory/竞对拆解/<竞对>.md。
```

生成帖子位时，系统会自动按「同平台 → 同市场 → 同类型 → 用得少 → 曝光高」给每个帖子位配一个对标样本。
